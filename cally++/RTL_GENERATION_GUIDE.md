# RTL 生成功能使用指南

## 功能说明

cally++ GUI 现在提供了一键生成 RTL expand 文件的功能。点击"生成 RTL"按钮后,系统会自动:

1. 编译 C++ 源文件生成 RTL expand 文件
2. 解析 RTL 文件并进行去改编处理
3. 将生成的 expand 文件自动填充到输入框

## 使用步骤

### 1. 启动 GUI

```bash
cd /path/to/cally++
python3 gui.py
```

### 2. 选择源文件

- 点击"选择源文件"按钮,选择你的 C++ 源代码文件
