# 任意位置文件读取说明

## 概述

mycallypro 和 dag_describe 都支持从文件系统的**任意位置**读取 C 源文件和 expand 文件，无需将文件复制到特定目录。

---

## 📁 当前三阶段架构

### 阶段划分

```
阶段1 - 输入：从任意位置读取
阶段2 - 处理：mycallypro/中间结果/
阶段3 - 输出：mycallypro/配置文件/
```

### 核心原则

- ✅ **输入文件**：可以在文件系统的任意位置
- ✅ **处理过程**：中间结果自动保存到 `mycallypro/中间结果/`
- ✅ **输出文件**：配置文件自动保存到 `mycallypro/配置文件/`

---

## 🚀 使用方法

### 1. mycallypro 命令行

#### 基础用法

```bash
# 从任意位置读取expand文件
python3 -m mycallypro /path/to/anywhere/file.c.233r.expand

# 指定源文件位置
python3 -m mycallypro /path/to/anywhere/file.c.233r.expand \
    --source-file /path/to/anywhere/file.c

# 生成配置文件
python3 -m mycallypro /path/to/anywhere/file.c.233r.expand \
    --export-txt circle.txt \
    --source-file /path/to/anywhere/file.c
```

#### 示例

```bash
# 示例1: 从桌面读取
python3 -m mycallypro ~/桌面/project/main.c.233r.expand --export-txt circle.txt

# 示例2: 从Downloads读取
python3 -m mycallypro ~/Downloads/test.c.233r.expand --export-txt circle.txt

# 示例3: 从绝对路径读取
python3 -m mycallypro /home/user/projects/app/source.c.233r.expand --export-txt circle.txt

# 示例4: 指定输出位置
python3 -m mycallypro /path/to/input.expand \
    --export-txt circle.txt \
    --output-base /home/chove/桌面/cally/mycallypro
```

### 2. mycallypro GUI

#### 使用步骤

1. **启动GUI**
   ```bash
   python3 -m mycallypro.gui
   ```

2. **读入C文件**（可选）
   - 点击 "读入 C 文件" 按钮
   - 在文件选择对话框中选择**任意位置**的 C 源文件
   - GUI会自动编译生成 expand 文件

3. **读入expand文件**
   - 点击 "读入 expand 文件" 按钮
   - 在文件选择对话框中选择**任意位置**的 expand 文件
   - 支持绝对路径、相对路径、包含中文的路径

4. **生成配置文件**
   - 点击 "生成配置文件" 按钮
   - 所有输出自动保存到 `mycallypro/配置文件/<basename>/`

#### GUI特性

- ✅ 文件选择对话框支持浏览整个文件系统
- ✅ 自动处理中文路径和特殊字符
- ✅ 显示完整的文件路径
- ✅ 支持冗余处理模式（智能检测、清理重建）

### 3. dag_describe

dag_describe 工具也支持从任意位置读取配置文件。

#### 使用方法

```bash
# 从任意位置读取配置文件
cd test
python3 dag_describe.py /path/to/anywhere/circle.txt

# 从mycallypro生成的配置文件读取
python3 dag_describe.py ../mycallypro/配置文件/produce.c/circle.txt
```

## 📊 文件路径处理

### 路径类型支持

| 路径类型 | 示例 | 支持 |
|---------|------|------|
| 绝对路径 | `/home/user/file.expand` | ✅ |
| 相对路径 | `./test/file.expand` | ✅ |
| 用户目录 | `~/project/file.expand` | ✅ |
| 中文路径 | `/home/用户/桌面/file.expand` | ✅ |
| 空格路径 | `/path/with space/file.expand` | ✅ |
| 符号链接 | `/link/to/file.expand` | ✅ |

### 自动处理

mycallypro 会自动：

1. **解析路径**：使用 `Path.resolve()` 解析为绝对路径
2. **验证文件**：检查文件是否存在和可读
3. **提取基础名**：从文件名提取基础名（如 `main.c` → `main`）
4. **创建输出目录**：自动在 `配置文件/<basename>/` 创建目录
5. **复制文件**：可选择复制源文件和expand文件到配置文件目录

## 🎯 输出目录结构

无论输入文件在何处，输出始终遵循三阶段结构：

### 配置文件目录（阶段3 - 最终输出）

```
mycallypro/配置文件/<basename>/
├── circle.txt              # 主配置文件
├── <basename>.dot          # DAG图（线程视图）
├── <basename>_full.dot     # DAG图（完整视图）
├── <basename>.c            # 源代码副本（可选）
└── <basename>.c.233r.expand # expand文件副本（可选）
```

### 中间结果目录（阶段2 - 处理过程）

```
mycallypro/中间结果/<basename>/
├── debug/                  # 调试JSON文件
├── images/                 # PNG图片
├── temp/                   # 临时DOT文件
└── logs/                   # 日志文件
```

## 🔧 技术实现

### 路径解析

```python
from pathlib import Path

# 用户提供的路径（可以是任意位置）
input_path = "/home/user/桌面/project/main.c.233r.expand"

# 解析为绝对路径
expand_path = Path(input_path).resolve()

# 提取基础名
base_name = expand_path.stem.replace('.c.233r', '')

# 生成输出路径
config_dir = Path("/home/chove/桌面/cally/mycallypro/配置文件") / base_name
```

### 工作目录设置

```python
# GUI调用mycallypro时的工作目录
PROJECT_ROOT = Path(__file__).resolve().parent  # mycallypro目录
work_dir = PROJECT_ROOT.parent  # cally目录

# 确保能正确找到mycallypro模块
subprocess.run(
    ["python3", "-m", "mycallypro", str(expand_path)],
    cwd=str(work_dir)
)
```

## 💡 使用技巧

### 技巧1：使用GUI浏览文件

GUI的文件选择对话框允许您浏览整个文件系统，比命令行输入路径更方便。

### 技巧2：批处理多个文件

```bash
# 处理目录中的所有expand文件
for file in /path/to/directory/*.expand; do
    python3 -m mycallypro "$file" --export-txt circle.txt
done
```

### 技巧3：使用符号链接

如果文件在很深的目录中，可以创建符号链接：

```bash
# 创建符号链接到桌面
ln -s /very/long/path/to/file.expand ~/桌面/file.expand

# 使用链接文件
python3 -m mycallypro ~/桌面/file.expand --export-txt circle.txt
```

### 技巧4：设置默认输出位置

```bash
# 使用别名设置默认输出位置
alias mycally="python3 -m mycallypro --output-base /home/chove/桌面/cally/mycallypro"

# 使用别名
mycally /any/path/file.expand --export-txt circle.txt
```

## ⚠️ 注意事项

### 1. 文件权限

确保对输入文件有**读取权限**：

```bash
# 检查文件权限
ls -l /path/to/file.expand

# 如果没有权限，添加读取权限
chmod +r /path/to/file.expand
```

### 2. 中文路径

虽然支持中文路径，但建议：

- ✅ 使用英文路径更加通用
- ✅ 避免使用特殊字符（如 `*`, `?`, `|`）
- ✅ 路径中的空格用引号包围

```bash
# 正确：使用引号包围含空格的路径
python3 -m mycallypro "/path/with space/file.expand"

# 错误：不使用引号
python3 -m mycallypro /path/with space/file.expand
```

### 3. 相对路径

使用相对路径时，确保从正确的目录运行命令：

```bash
# 当前在 /home/user/
python3 -m mycallypro ./project/file.expand  # 读取 /home/user/project/file.expand

# 当前在 /home/user/other/
python3 -m mycallypro ./project/file.expand  # 读取 /home/user/other/project/file.expand
```

### 4. 输出目录

输出目录由 `--output-base` 参数控制：

```bash
# 默认：输出到 mycallypro 目录
python3 -m mycallypro /any/path/file.expand --export-txt circle.txt

# 自定义：指定输出位置
python3 -m mycallypro /any/path/file.expand \
    --export-txt circle.txt \
    --output-base /custom/output/path
```

## 🐛 故障排除

### 问题1：找不到文件

**症状**：
```
ERROR: Can't open rtl file, "/path/to/file.expand"!
```

**解决**：
1. 检查文件路径是否正确：`ls -l /path/to/file.expand`
2. 使用绝对路径而不是相对路径
3. 检查文件权限：`chmod +r /path/to/file.expand`

### 问题2：No module named mycallypro

**症状**：
```
/usr/bin/python3: No module named mycallypro
```

**解决**：
1. 确保从正确的工作目录运行（项目根目录）
2. 检查 PYTHONPATH 是否包含项目目录
3. 使用完整路径：`cd /home/chove/桌面/cally && python3 -m mycallypro ...`

### 问题3：GUI生成失败

**症状**：GUI显示"生成失败"对话框

**解决**：
1. 检查终端输出的详细错误信息
2. 确认expand文件路径正确
3. 尝试在命令行直接运行相同的命令
4. 查看 `mycallypro/中间结果/<basename>/debug/` 中的日志
