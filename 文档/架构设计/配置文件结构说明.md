# MyCallypro 配置文件结构说明

## 配置文件目录结构

参考 `test/配置文件/` 的设计，mycallypro 采用**扁平化结构**。

### 目录布局

```
mycallypro/配置文件/<basename>/
├── circle.txt                  # dag_describe主配置文件
├── <basename>.dot              # DAG图（线程视图）
├── <basename>_full.dot         # DAG图（完整视图）
├── <basename>.c                # 源代码副本
└── <basename>.c.233r.expand    # expand文件副本
```

### 实际示例：produce.c

```bash
$ tree mycallypro/配置文件/produce.c/
mycallypro/配置文件/produce.c/
├── circle.txt                      # 684 bytes
├── produce.c.dot                   # 2.6 KB
├── produce.c_full.dot              # 完整视图（如果生成）
├── produce.c                       # 3.6 KB
└── produce.c.233r.expand           # 46 KB
```

## 命名规则

| 文件类型 | 命名规则 | 说明 |
|---------|---------|------|
| 目录 | `<basename>` | 从expand文件提取，如 `produce.c` |
| 配置文件 | `circle.txt` | 固定名称 |
| 线程视图DOT | `<basename>.dot` | 如 `produce.c.dot` |
| 完整视图DOT | `<basename>_full.dot` | 如 `produce.c_full.dot` |
| 源文件 | 原始文件名 | 如 `produce.c` |
| Expand文件 | 原始文件名 | 如 `produce.c.233r.expand` |

## 使用方法

### 生成配置文件

```bash
cd /home/chove/桌面/cally

# 基本用法
python3 -m mycallypro <expand_file> \
    --export-txt circle.txt \
    --source-file <source_file>

# 示例
python3 -m mycallypro mycallypro/源文件/produce3/produce.c.233r.expand \
    --export-txt circle.txt \
    --source-file mycallypro/源文件/produce3/produce.c
```

### dag_describe 读取配置

```bash
cd test/dag_describe

# 使用mycallypro生成的配置
python3 dag_describe.py ../../mycallypro/配置文件/produce.c/circle.txt
```

## 对比 test/配置文件/

### test 结构
```
test/配置文件/dag/
├── circle.txt
└── produce_4.dot
```

### mycallypro 结构
```
mycallypro/配置文件/produce.c/
├── circle.txt
├── produce.c.dot
├── produce.c
└── produce.c.233r.expand
```

### 相同点
✅ 扁平化结构，无子目录  
✅ circle.txt 在根目录  
✅ DOT 文件在根目录  
✅ 便于直接访问

### 差异
- mycallypro 额外保留源文件和expand文件副本
- mycallypro 使用规范化的文件命名
- mycallypro 支持生成多个DOT文件（线程视图、完整视图）

## 中间结果目录

PNG图片和临时文件存储在中间结果目录，不影响配置文件：

```
mycallypro/中间结果/produce.c/
├── debug/                  # 调试JSON
├── temp/                   # 临时DOT
├── images/                 # PNG图片
│   ├── produce.c.png
│   └── produce.c_full.png
└── logs/                   # 日志文件
```

## circle.txt 格式

```
互斥量
producer/while/pthread_mutex_lock2 mutex buf_mutex1 34 produce.c
producer/while/pthread_mutex_unlock4 mutex buf_mutex1 41 produce.c

信号量
producer/while/sem_post5 semaphore full1 42 produce.c
consumer/sem_wait1 semaphore full1 50 produce.c

条件变量
consumer/if/pthread_cond_broadcast4 condition cond1 61 produce.c
watcher/while/pthread_cond_wait2 condition cond1 76 produce.c
```

格式：`节点路径 类型 变量名 行号 文件名`（5列，空格分隔）

## 文件清理

```bash
# 清理配置文件
rm -rf mycallypro/配置文件/*

# 清理中间结果
rm -rf mycallypro/中间结果/*

# 清理特定项目
rm -rf mycallypro/配置文件/produce.c mycallypro/中间结果/produce.c
```
