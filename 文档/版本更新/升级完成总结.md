## ⚙️ 技术细节

### 文件生成位置
```
配置文件/
└── <源文件名>/
    ├── dag.dot           # 自动生成
    ├── dag.png           # 点击"生成dag图"时渲染
    ├── conditions.dot    # 自动生成
    ├── conditions.png    # 点击"查看条件节点"时渲染
    └── circle.txt        # 自动生成
```

### 调用链
```
load_source_file()
  ├─> _auto_generate_dag("--threads-only", "dag.dot")
  │     └─> subprocess.run([python, -m, legacy, expand_file, --threads-only])
  │
  ├─> _auto_generate_dag("--conditions-only", "conditions.dot")
  │     └─> subprocess.run([python, -m, legacy, expand_file, --conditions-only])
  │
  └─> _auto_generate_circle_txt()
        └─> subprocess.run([python, -m, legacy, expand_file, --export-txt, circle.txt])

load_dag_graph()
  └─> subprocess.run([dot, -Tpng, dag.dot, -o, dag.png])
      └─> _show_image(dag.png)

view_condition_nodes()
  └─> subprocess.run([dot, -Tpng, conditions.dot, -o, conditions.png])
      └─> _show_image(conditions.png)
```
