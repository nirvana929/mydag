## 新工作流程

### "选择源文件"按钮 - 全自动生成

点击"选择源文件"后，系统自动执行7个步骤：

```
进度提示（状态栏显示）:
┌────────────────────────────────────────┐
│ 正在生成... (1/7) 处理源文件            │
├────────────────────────────────────────┤
│ 正在生成... (2/7) 生成dag图DOT文件      │
├────────────────────────────────────────┤
│ 正在生成... (3/7) 生成条件节点DOT文件    │
├────────────────────────────────────────┤
│ 正在生成... (4/7) 生成配置文件          │
├────────────────────────────────────────┤
│ 正在生成... (5/7) 生成原始图            │
├────────────────────────────────────────┤
│ 正在生成... (6/7) 生成互斥锁图          │
├────────────────────────────────────────┤
│ 正在生成... (7/7) 生成信号量图          │
└────────────────────────────────────────┘
```

#### 步骤详情

**步骤1: 处理源文件**
- 如果是 C 文件 → 编译生成 expand → 保存到 `rtl文件/`
- 如果是 expand 文件 → 直接复制到 `rtl文件/`

**步骤2: 生成dag.dot**
- 调用 `legacy.main()` with `--threads-only`
- 生成 `dag.dot` 和 `dag.png`
- 保存到 `生成dag图/`

**步骤3: 生成conditions.dot（完整DAG）**
- 调用 `legacy.main()` with `--conditions-only`
- 生成 `conditions.dot` 和 `conditions.png`
- 保存到 `查看条件节点/`

**步骤4: 生成circle.txt**
- 调用 `legacy.main()` with `--export-txt`
- 生成 `circle.txt`
- 保存到 `配置文件/`

**步骤5: 生成原始图**
- 基于 `conditions.dot`
- 生成 `original.png`
- 保存到 `生成原始图/`

**步骤6: 生成互斥锁图**
- 基于 `conditions.dot` 和 `circle.txt`
- 生成 `mutex.png`
- 保存到 `查看互斥锁图/`

**步骤7: 生成信号量图**
- 基于 `conditions.dot` 和 `circle.txt`
- 生成 3 个文件：
  - `semaphore.png` - 主图
  - `tarjan.png` - Tarjan SCC 图
  - `threads.png` - 线程图
- 保存到 `生成信号量图/`

### 错误处理

**策略**: 记录错误但继续执行（C策略）

- 如果某步失败，记录错误但继续后续步骤
- 所有步骤完成后，统一显示错误报告
- 用户可以看到哪些步骤成功，哪些失败

**示例**:
```
生成完成，但有以下错误：

[步骤5] 生成原始图失败: Graphviz未安装
[步骤6] 生成互斥锁图失败: 依赖文件不存在
```
