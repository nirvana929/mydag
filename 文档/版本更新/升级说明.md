# Mycallyplus 升级说明

**升级日期**: 2025年10月28日

## 升级内容

### 1. 按钮文字修改

| 原按钮名称 | 新按钮名称 | 说明 |
|-----------|-----------|------|
| 生成线程DAG | **生成dag图** | 功能改为仅加载已生成的 dag.dot |
| 生成条件DAG | **查看条件节点** | 功能改为仅加载已生成的 conditions.dot |

### 2. 方法重命名

| 原方法名 | 新方法名 | 功能变化 |
|---------|---------|---------|
| `generate_threads_dag()` | `load_dag_graph()` | 从"生成+显示" → "仅加载+显示" |
| `generate_conditions_dag()` | `view_condition_nodes()` | 从"生成+显示" → "仅加载+显示" |

### 3. 新增方法

| 方法名 | 功能 |
|-------|------|
| `_auto_generate_dag(mode, output_name)` | 自动生成DAG文件（内部调用） |
| `_auto_generate_circle_txt()` | 自动生成circle.txt（内部调用） |

### 4. 工作流变化

#### 原工作流
```
用户操作：
1. 点击"选择源文件" → 加载 .c 或 .expand 文件
2. 点击"生成线程DAG" → 调用 legacy.main() 生成 dag.dot → 显示
3. 点击"生成条件DAG" → 调用 legacy.main() 生成 conditions.dot → 显示
4. 点击"生成配置文件" → 生成 circle.txt
```

#### 新工作流
```
用户操作：
1. 点击"选择源文件" → 加载 .c 或 .expand 文件
   ↓
   【自动执行】
   - 生成 dag.dot (--threads-only)
   - 生成 conditions.dot (--conditions-only)
   - 生成 circle.txt
   ↓
2. 点击"生成dag图" → 直接加载 dag.dot → 渲染为 PNG → 显示
3. 点击"查看条件节点" → 直接加载 conditions.dot → 渲染为 PNG → 显示
```

## 升级优势

### 🚀 提升效率
- **一键完成**: 选择源文件后自动生成所有必需文件，无需多次点击
- **快速查看**: "生成dag图"和"查看条件节点"秒开，无需重新生成

### 🎯 降低复杂度
- **简化操作**: 从4步操作减少到1步自动+按需查看
- **减少等待**: 避免重复生成已有文件

### 🔧 保持兼容
- **保留功能**: 所有原有功能均保留
- **API一致**: 外部调用接口保持不变

## 升级细节

### `load_source_file()` 修改

**修改前**:
```python
def load_source_file(self) -> None:
    """选择源文件（C或expand）"""
    # ... 加载文件 ...
    messagebox.showinfo("成功", f"已加载文件：\n{path.name}")
```

**修改后**:
```python
def load_source_file(self) -> None:
    """选择源文件（C或expand），并自动生成所有必需文件"""
    # ... 加载文件 ...
    
    # 自动生成所有文件
    try:
        # 1. 生成 dag.dot (threads)
        self._auto_generate_dag("--threads-only", "dag.dot")
        
        # 2. 生成条件相关文件 (conditions)
        self._auto_generate_dag("--conditions-only", "conditions.dot")
        
        # 3. 生成 circle.txt
        self._auto_generate_circle_txt()
        
        messagebox.showinfo("成功", 
            f"已加载文件并完成自动生成：\n"
            f"- {path.name}\n"
            f"- dag.dot\n"
            f"- conditions.dot\n"
            f"- circle.txt\n\n"
            f"现在可以点击【生成dag图】或【查看条件节点】查看结果")
    except Exception as exc:
        messagebox.showerror("自动生成失败", str(exc))
```

### `load_dag_graph()` (原 `generate_threads_dag()`)

**修改前**:
```python
def generate_threads_dag(self) -> None:
    """生成线程DAG（--threads-only）"""
    self._generate_dag_internal("--threads-only")  # 调用 legacy.main()
```

**修改后**:
```python
def load_dag_graph(self) -> None:
    """加载并显示 dag.dot 图"""
    # 确定配置目录
    config_dir = self.base_dir / "配置文件" / base_name
    dag_dot = config_dir / "dag.dot"
    
    if not dag_dot.exists():
        messagebox.showerror("错误", "dag.dot 文件不存在，请先选择源文件")
        return
    
    # 渲染为PNG
    png_path = config_dir / "dag.png"
    subprocess.run(["dot", "-Tpng", str(dag_dot), "-o", str(png_path)], check=True)
    
    # 加载图到可视化区
    self._show_image(png_path)
    messagebox.showinfo("成功", "已加载dag图")
```
