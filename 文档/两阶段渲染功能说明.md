# 两阶段渲染功能实现说明

## 功能概述

按照您的要求，已将渲染功能分为两个阶段：

1. **线程视图**：仅处理线程补边，不处理条件节点
2. **条件视图**：在线程补边基础上，添加条件节点处理

## 实现细节

### 1. 代码修改

#### legacy.py
- 在 `full_call_graph()` 函数中添加了 `threads_only` 参数
- 当 `threads_only=True` 时，跳过条件节点处理（if/while/switch）
- 添加了 `--threads-only` 命令行参数

#### gui.py
- 修改了 `generate_dag()` 方法，调用线程视图模式
- 修改了 `generate_conditions_dag()` 方法，调用完整视图模式
- 更新了文件命名：`dag.dot/dag.png` 和 `dag_full.dot/dag_full.png`

### 2. 文件输出

#### 线程视图
- **DOT文件**：`mycallypro/test/<basename>/dag.dot`
- **PNG文件**：`mycallypro/test/<basename>/dag.png`
- **内容**：仅包含线程补边，无条件节点样式

#### 条件视图
- **DOT文件**：`mycallypro/test/<basename>/dag_full.dot`
- **PNG文件**：`mycallypro/test/<basename>/dag_full.png`
- **内容**：包含线程补边 + 条件节点虚线样式

### 3. 使用方式

#### CLI 模式
```bash
# 线程视图
python3 -m mycallypro --threads-only <file.expand>

# 条件视图（默认）
python3 -m mycallypro <file.expand>
```

#### GUI 模式
- **"生成 dag 图"** 按钮：生成线程视图
- **"查看条件节点"** 按钮：生成条件视图

## 路径变更

**重要更新**：所有生成的文件现在都存放在 `mycallypro/test/<basename>/` 目录下，而不是根目录的 `test/` 文件夹。

### 路径修改详情：
- **legacy.py**：修改了 `_ensure_debug_dir()` 函数，使用 `Path(__file__).parent / "test"` 
- **gui.py**：修改了所有 `target_dir` 设置，使用 `Path(__file__).parent / "test"`

## 技术要点

1. **向后兼容**：默认行为保持不变（完整视图）
2. **参数控制**：通过 `threads_only` 参数精确控制渲染行为
3. **文件分离**：两套文件互不覆盖，便于对比分析
4. **路径统一**：所有生成文件都存放在 `mycallypro/test/` 目录下
5. **错误处理**：保持原有的错误处理机制
