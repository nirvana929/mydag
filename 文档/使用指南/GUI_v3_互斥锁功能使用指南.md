## 📖 基础操作流程

### 步骤1: 选择源文件
点击 **"1. 选择源文件"** 按钮
- 选择要分析的C源文件（如 `main.c`）
- 程序会自动创建工作目录结构

### 步骤2: 选择expand文件（可选）
点击 **"1.5 选择expand文件"** 按钮 ⭐ *新功能*
- 选择expand文件（如 `main.c.233r.expand`）
- 可覆盖之前的expand文件
- 自动复制到工作目录

### 步骤3: 生成dag图
点击 **"2. 生成dag图"**
- 生成基础的控制流图

### 步骤4: 查看条件节点
点击 **"3. 查看条件节点"**
- 生成完整的dag图
- 生成 `circle.txt` 配置文件（包含互斥锁信息）

### 步骤5: 查看互斥锁 ⭐ *核心功能*
点击 **"5. 查看互斥锁"**
- 解析互斥锁配对信息
- 分析互斥锁覆盖区域
- 显示子功能按钮区

## 🎨 互斥锁子功能

### 子功能1: 查看互斥锁图 🖼️

**触发方式**:
- 点击 "5. 查看互斥锁" 后自动显示
- 或点击子功能按钮 **"查看互斥锁图"**

**功能特点**:
- ✅ 彩色子图显示每个互斥锁

## 🎯 子功能切换

在查看互斥锁后，屏幕底部会出现子功能按钮区：

```
┌──────────────────────────────────────────┐
│                                          │
│         [主显示区域]                     │
│                                          │
└──────────────────────────────────────────┘
┌──────────────────────────────────────────┐
│ [查看互斥锁图]  [查看互斥锁信息]        │ ← 子功能按钮
└──────────────────────────────────────────┘
```

**操作**:
- 点击 **"查看互斥锁图"** → 切换到图形视图
- 点击 **"查看互斥锁信息"** → 切换到文本视图
- 可以随时在两个视图之间切换

## 🔧 常见问题

### Q1: 子功能按钮没有显示？
**原因**: 互斥锁数据未准备好
**解决**: 
1. 确保已完成步骤3（查看条件节点）
2. 确保 `circle.txt` 中有互斥锁信息
3. 重新点击"5. 查看互斥锁"

### Q2: 提示"未找到互斥锁配对信息"？
**原因**: `circle.txt` 中没有互斥锁数据
**解决**:
1. 检查源代码是否使用了互斥锁（pthread_mutex_lock/unlock）
2. 重新运行步骤3生成 `circle.txt`
3. 手动检查 `circle.txt` 内容

### Q3: 图片无法显示？
**原因**: Graphviz未安装或路径问题
**解决**:
```bash
# Ubuntu/Debian
sudo apt-get install graphviz

# 检查安装
dot -V
```

### Q4: 选择expand文件后没有反应？
**原因**: 可能是权限问题或路径问题
**解决**:
1. 检查文件是否可读
2. 查看终端输出的错误信息
3. 确保有写入工作目录的权限

## 💡 使用技巧

### 技巧1: 快速定位互斥锁
1. 先用"查看互斥锁信息"了解整体情况
2. 记下感兴趣的互斥锁ID
3. 切换到"查看互斥锁图"查看图形
4. 在图中找到对应颜色的子图

### 技巧2: 分析互斥锁覆盖范围
- 查看 COVERED 列表
- LOCK和UNLOCK之间的所有节点都被保护
- 注意是否有嵌套的互斥锁

### 技巧3: 理解颜色编码
- 每个不同的互斥锁变量分配一个颜色
- 相同变量的lock/unlock配对用相同颜色
- 12种颜色循环使用

### 技巧4: 导出图片
生成的图片保存在：
```
中间结果/<源文件名>/查看互斥锁/mutex_graph.png
```
可以直接复制到其他位置使用
